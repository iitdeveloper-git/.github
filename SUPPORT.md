# Support for IITDEVELOPER Projects

Welcome to the **IITDEVELOPER** support center. We build and maintain intelligent software platforms, enterprise identity systems, notification infrastructure, and cloud-native solutions.

---

## 🛠️ How to Get Help

Depending on your need, please use the following support channels:

### 1. Public Repositories & Open Source
* **Bug Reports & Issues**: If you encounter a defect in an active repository, open an issue using the [Bug Report Template](./.github/ISSUE_TEMPLATE/bug_report.yml).
* **Feature Requests**: Propose new capabilities or improvements via the [Feature Request Template](./.github/ISSUE_TEMPLATE/feature_request.yml).
* **Documentation Issues**: Submit documentation corrections via the [Documentation Template](./.github/ISSUE_TEMPLATE/documentation.yml).

### 2. Enterprise & Commercial Solutions
For commercial inquiries, enterprise deployments, bespoke engineering, or SLA-backed support contracts:
* **Website**: [https://iitdeveloper.com](https://iitdeveloper.com)
* **Email**: [info@iitdeveloper.com](mailto:info@iitdeveloper.com)

### 3. Security Inquiries
For security disclosures and vulnerability reports:
* Follow the guidelines in our [Security Policy](./SECURITY.md).
* Direct email: [security@iitdeveloper.com](mailto:security@iitdeveloper.com) (or [info@iitdeveloper.com](mailto:info@iitdeveloper.com)).
